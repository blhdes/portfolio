# Tool marks (CV page)

Monochrome brand marks from Simple Icons 15.22.0 (CC0), each traced from the brand's official asset listed below. Brands keep their trademarks; used here only to name the tools.

- `claude.svg`: Claude, https://claude.ai
- `modelcontextprotocol.svg`: Model Context Protocol, https://github.com/modelcontextprotocol/docs/blob/573dc60c2e7aab2605b29d0bf27194aa7b02e4fb/logo/light.svg
- `python.svg`: Python, https://www.python.org/community/logos/
- `obsidian.svg`: Obsidian, https://obsidian.md
- `swift.svg`: Swift, https://developer.apple.com/swift/resources/
- `typescript.svg`: TypeScript, https://www.typescriptlang.org/branding
- `react.svg`: React, https://github.com/facebook/create-react-app/blob/282c03f9525fdf8061ffa1ec50dce89296d916bd/test/fixtures/relative-paths/src/logo.svg
- `nodedotjs.svg`: Node.js, https://nodejs.org/en/about/branding
- `xcode.svg`: Xcode, https://developer.apple.com/develop
- `git.svg`: Git, https://git-scm.com/downloads/logos
- `github.svg`: GitHub, https://github.com/logos
- `gnubash.svg`: GNU Bash, https://github.com/odb/official-bash-logo/tree/61eff022f2dad3c7468f5deb4f06652d15f2c143
- `linux.svg`: Linux, https://www.linuxfoundation.org/the-linux-mark/
- `appstore.svg`: App Store, https://developer.apple.com/app-store
- `nextdotjs.svg`: Next.js, https://vercel.com/design/brands#next-js
- `supabase.svg`: Supabase, https://github.com/supabase/supabase/blob/4031a7549f5d46da7bc79c01d56be4177dc7c114/packages/common/assets/images/supabase-logo-wordmark--light.svg

JavaScript, CSS and C have no official logo (the marks in circulation are community-made), so they appear as text only.
